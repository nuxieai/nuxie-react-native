# Expo SDK Lab

This host uses Expo 57 and React Native 0.86.3. It loads the same [SDK Lab](../shared/lab.tsx) as the bare host.

Prepare the SDK's pinned native artifacts, install this host's dependencies, run `pnpm --ignore-workspace exec expo prebuild --no-install`, install iOS pods, then run `pnpm --ignore-workspace ios` or `pnpm --ignore-workspace android`. See [development instructions](../../docs/development.md).

Use a development build; Expo Go cannot load Nuxie. No Nuxie plugin configuration is required. Native directories are generated by prebuild. Keep the package, app config and lockfile as their source of truth.
